Guardar en GitHub

Para que las materias que marcás queden guardadas en el repo (y se vean igual en la compu y en el celular), la página necesita una clave de GitHub. Se guarda solo en este navegador, nunca en el repo.

  1. Entrá a github.com → crear clave (fine-grained token).
  2. Nombre: por ejemplo pagina-isi. Vencimiento: el que quieras.
  3. En Repository access elegí Only select repositories y marcá UTN---Sistemas.
  4. En Permissions → Repository permissions → Contents elegí Read and write.
  5. Tocá Generate token, copiá la clave (empieza con github_pat_) y pegala acá.
